## Installation
1. *Code → Download ZIP* (or the latest ZIP from **Releases**).
2. Copy the `WowSimsExporter` folder into `World of Warcraft/Interface/AddOns/`.
   In the ZIP it sits inside `WSE-WowSimsExporter_patched-Wow-3.3.5a-main` – copy only the inner `WowSimsExporter` folder.
3. Restart the game.
